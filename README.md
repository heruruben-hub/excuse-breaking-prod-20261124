## The entry

`main.py` writes a single line — one excuse, from the machine's own mouth, 180 characters or less — to `/output/entry.txt`. It validates the line (one line, 1–180 characters, not whitespace only), writes it exactly with no trailing newline, then reads the file back and checks the content is byte-for-byte what was written.

## Run it

```sh
python3 main.py
```
